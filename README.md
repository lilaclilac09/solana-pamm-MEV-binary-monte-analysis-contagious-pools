this is an experimental research repo for simulating how mev pressure, liquidity shocks, and routing structures can create contagious behavior across connected solana pools

i built it to understand one question:

when one pool gets hit, how does the damage travel?

it is not a trading bot or production infrastructure
it is a research artifact for studying mechanism, risk, and propagation

simulating how mev pressure and liquidity shocks propagate across connected solana pools
